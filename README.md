# World of Pieces · descargas

Acá se publican los builds de prueba de **World of Pieces**, un RPG 3D independiente: un mundo partido en islas, un
combate que se apunta con el mouse, 9 clases, 6 razas, barcos, oficios y mazmorras. Este repositorio tiene solo las
descargas (sin el código del juego).

**Bajá la última versión en [Releases](../../releases).** Más información, guías y la wiki, en la web oficial:
https://world-of-pieces.pages.dev

## Cómo jugar la alpha

1. Descargá el `.zip` del release más nuevo (sección *Assets*).
2. Descomprimilo en una carpeta tuya y abrí `WorldOfPieces.exe`.
3. Si Windows muestra "Windows protegió tu PC", tocá "Más información" y "Ejecutar de todas formas" (el juego todavía no
   tiene una firma digital paga).

Requisitos: Windows 10 u 11 de 64 bits, una placa de video con OpenGL 3.3, 4 GB de memoria. Para jugar con amigos,
Steam abierto.

La alpha es **gratis**, y quien la consiga ahora va a tener el juego gratis para siempre. Es una versión en desarrollo:
tiene errores y el guardado puede cambiar entre versiones. Por ahora el juego está en español.

# World of Pieces · downloads

Test builds of **World of Pieces**, an independent 3D RPG: a world broken into islands, combat you aim with the mouse,
9 classes, 6 races, ships, professions and dungeons. This repository only hosts the downloads (not the game's code).

**Get the latest version under [Releases](../../releases).** More info, guides and the wiki on the official website:
https://world-of-pieces.pages.dev

The alpha is **free**, and whoever gets it now keeps the game free forever. It is a work in progress: expect bugs, and
save data may change between versions. The game is in Spanish for now; the English translation is planned.
